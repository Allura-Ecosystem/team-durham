# Team Durham BMad Module Setup

Register Team Durham with BMad help without replacing the existing Claude/Codex/OpenCode
plugin. Read `assets/module.yaml` and `assets/module-help.csv`, run `bmad-bmb-setup` or
the BMad module installer, and set the plugin source plus approved Allura tenant.

Verify `bmad-help` exposes the Durham menu codes. If the Team Durham plugin is not present,
report `blocked`; do not invent specialist output or external publishing actions.
