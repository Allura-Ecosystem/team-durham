# Session start

obtain or reuse its ContextPacket v1.1. Scout checks local strategy, artifacts,
and authority; one focused Brain search covers relevant decisions and blockers
with `group_id: allura-team-durham`. Use the exact available tool name and inspect
the receipt before claiming hydration. Pure path lookup may skip Brain.

Reuse the packet across slices and handoffs. Compare dependency revisions and
approval references; refresh changed sources only. Unknown revisions require
re-reading. A different client, tenant, or task requires a fresh packet.

Report active role, route, owner, context sources and Brain status. Route clear
tasks directly within permissions; show a menu only when requested or unclear.
Load only the selected role and relevant skills. No mandatory session-start write
or database health query. Log a meaningful verified outcome through governed
Brain tools, read back before claiming persistence, and keep promotion human-gated.

If Brain is unavailable, disclose local-only context; do not infer missing history
or fall back to SQL, graph mutation, or local memory banks. Stop only if required
brand evidence or authority cannot be established from available sources.
